# IR-and-Buzzer
# IR Sensor with Buzzer – Obstacle Detection

# About
A simple Arduino project that detects nearby obstacles using an IR sensor and gives an audio alert through a buzzer. When no obstacle is detected, the Serial Monitor displays "1". When an obstacle is detected, it displays "0" and the buzzer beeps.

# Components Required
- Arduino Uno
- IR Sensor Module
- Buzzer
- Jumper Wires
- Breadboard

# Working
1. The IR sensor emits infrared light.
2. When an obstacle is detected, the sensor sends a digital signal to Arduino.
3. The Serial Monitor displays "0" when an obstacle is detected and "1" when no obstacle is detected.
4. The buzzer beeps whenever an obstacle is detected.
